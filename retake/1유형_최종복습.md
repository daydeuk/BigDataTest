# ① 핵심 한 장

## 0. 파이썬 괄호 3종 — 헷갈리면 여기부터

| 괄호 | 하는 일 | 예 |
|---|---|---|
| `( )` | **함수 실행** · 조건 묶기 | `df.head()`, `round(x, 2)`, `(df['a'] > 1) & (df['b'] < 2)` |
| `[ ]` | **꺼내기** · 목록 | `df['price']`, `df[조건]`, `s.iloc[0]`, `['서울', '부산']` |
| `{ }` | **사전** (이름: 값) | `pd.DataFrame({'pred': pred})`, `answer = {'A1-a': 7}` |

> 함수엔 `( )`가 꼭 붙는다: `mean()`, `sum()`, `tolist()`, `day_name()`. 붙이지 않는 것(속성): `shape`, `index`, `columns`, `.dt.month`, `.dt.dayofweek`

## 1. 결과가 어떤 모양인지 알아야 꺼낼 수 있다

| 코드 결과 | 모양 | 값 하나 꺼내기 |
|---|---|---|
| `df[조건]`, `sort_values(…)` | **DataFrame** (표) | `len(df[조건])` 행 수 / `df[조건]['col'].mean()` / **`.iloc[N-1]['col']` N번째 행의 그 칸** (DataFrame도 iloc 됨. 행이 나오니 `['col']`까지 한 번 더) |
| `df['col']`, `groupby(…)['col'].mean()`, `value_counts()` | **Series** (이름표 + 값 한 줄) | `.iloc[N-1]` N번째 값 / `.index[N-1]` N번째 이름 / `.idxmax()` 최대인 이름 / `.loc['이름']` |
| `df['col'].mean()`, `.sum()`, `len(…)` | **숫자 하나** | 그대로 → `round()` / `int()` |
| 조건 `df['col'] > 3` | **True/False Series** | `.sum()` = 개수, `.mean()` = 비율 |

## 2. 문제 문장 → 코드 사전 ⭐

| 문제 문장 | 코드 |
|---|---|
| "몇 개 / 몇 건 / 몇 명" | `len(df[조건])` 또는 `조건.sum()` |
| "비율" | `조건.mean()` (그룹별: `groupby('g')['is_x'].mean()`) |
| "몇 종류" | `df['col'].nunique()` |
| "가장 많은 값(이름)과 그 개수" | `vc = df['col'].value_counts()` → `vc.index[0]`, `vc.iloc[0]` |
| "N번째로 큰 행의 ○○" | `df.sort_values('기준', ascending=False).iloc[N-1]['○○']` |
| ⭐️⭐️ "상위 N개의 ○○ 평균" | `df.sort_values('기준', ascending=False).head(N)['○○'].mean()` |
| "그룹별 ○○ 평균이 가장 큰 그룹" | `g = df.groupby('그룹')['○○'].mean()` → `g.idxmax()`, `g.max()` |
| "그룹별 … N번째로 큰 그룹" | `g.sort_values(ascending=False).index[N-1]` (groupby 결과는 **이름순**) |
| ⭐️⭐️ "**자기** 그룹 평균보다 큰" | `df['m'] = df.groupby('그룹')['x'].transform('mean')` → `df[df['x'] > df['m']]` |
| "조건에 맞는 이름 **전부**" | `s[s > 기준].index.tolist()` |
| "결측을 ○○로 채우고" | `df['c'] = df['c'].fillna(값)` (같은 컬럼 이름 두 번) |
| ⭐️⭐️ "결측을 **그룹 평균**으로" | `df['c'] = df['c'].fillna(df.groupby('g')['c'].transform('mean'))` |
| ⭐️⭐️ "조건에 맞는 행의 값을 바꿔라" | `df.loc[조건, '열'] = 새 값` |
| "○○가 들어간 / 시작하는" | `df['c'].str.contains('○○')` / `.str.startswith('○○')` |
| "대소문자 구분 없이" | `.str.lower()` 먼저 |
| ⭐️⭐️ "첫 단어 / N번째 조각" | `.str.split().str[0]` (`[0]`만 쓰면 행 하나 ❌) |
| ⭐️⭐️ "월 / 요일 / 시간" | `df['dt'] = pd.to_datetime(df['dt'])` → `.dt.month` / `.dt.dayofweek`(월=0…일=6) / `.dt.hour` |
| ⭐️⭐️ "구간으로 나눠" | `pd.cut(x, bins=[…], labels=[…])` — 기본 `(a, b]` "이하", "미만"이면 `right=False` |
| ⭐️⭐️ "IQR 이상치" | `q1, q3 = x.quantile(0.25), x.quantile(0.75)` → `iqr = q3 - q1` → `(x < q1 - 1.5*iqr) \| (x > q3 + 1.5*iqr)` |
| ⭐️⭐️ "차이의 절댓값" | `abs(a - b)` |
| "정수로" / "소수 N째 자리" | `int(x)` / `round(x, N)` |

## 3. 내 실수 Top 10 (오답노트에서)

| # | 실수 | 고치는 한 줄 |
|---|---|---|

| ⭐️⭐️ 4 | 정렬 후 `loc[0]` | 위치 = **`iloc`** |
| ⭐️⭐️ 5 | True/False를 `count()`·`len(조건)` | **`.sum()`** 또는 `len(df[조건])` |
| 6 | "건수"를 `sum()` | 건수 = 행 수 (`size()`, `value_counts()`) |

| 9 | 이름이 여러 개인데 `index[0]` | **`.index.tolist()`** |
| 10 | "보다 큰"인데 `>=` | 크다 `>` · 이상 `>=` |

## 4. `.copy()` 언제 붙이나 (11/27 A6 풀다가 나온 질문)

> **`sort_values()`는 처음부터 새 표를 만들어 주기 때문에 `.copy()`가 필요 없다.**

새 변수에서 값을 바꿨을 때 원본 df가 어떻게 되는지 (실행 확인):

| 코드 | 새 표? | 새 변수 값을 바꾸면 | `.copy()` |
|---|---|---|---|
| `srt = df.sort_values('x')` | ✅ 새 표 | 원본 그대로, 경고 없음 | **필요 없음** |
| `d = df` | ❌ 같은 표에 **이름만 하나 더** | **원본도 같이 바뀜** | **필요** → `d = df.copy()` |
| `sub = df[조건]` | 새 표 | 원본은 그대로지만 ⚠️ 경고 | 값을 바꿀 거면 필요 |
| `df2 = df.drop_duplicates()` | 새 표 | 원본은 그대로지만 ⚠️ 경고 | 컬럼을 추가할 거면 필요 (그래서 A1이 `.copy()`) |

> 헷갈리면: **값을 바꾸거나 컬럼을 추가할 표**에 `.copy()`. 붙여서 손해 보는 경우는 없다.
> ⚠️ 같이 기억: 정렬 결과는 **새 이름**에 담는다 (`srt = …`). `df = df['amount'].sort_values()`처럼 `df =`에 담으면 df가 amount 한 줄짜리가 돼서 다음 문제가 전부 망가진다 (A6에서 실제로 한 실수).
