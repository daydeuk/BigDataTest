## 1. transform — 별 3개가 전부 이것 (사전 42 · 45 / 실수 7)

**"자기 그룹 평균"이 나오면 `mean()`이 아니라 `transform('mean')`**

```python
df['m'] = df.groupby('g')['x'].transform('mean')            # 행마다 자기 그룹 평균
len(df[df['x'] > df['m']])                                   # 자기 그룹 평균보다 큰 건수
df['c'] = df['c'].fillna(df.groupby('g')['c'].transform('mean'))   # 결측 → 그룹 평균
```

| 코드 | 결과 |
|---|---|
| ✅ `transform('mean')` | `[30, 30, 30, 7, 7, 7]` (행 수 그대로) |
| 🔇 `df['m'] = groupby(…).mean()` | `[nan, nan, …]`, 건수 **0** |
| 🔇 `fillna(groupby(…).mean())` | 결측이 **하나도 안 채워짐** |

> 왜? `mean()`은 그룹 수(2줄)짜리라 행(6줄)과 이름표가 안 맞는다. transform은 **행 수 그대로** 돌려준다.
> ⭐️⭐️⭐️⭐️⭐️ C1 "이거 어렵다" → **두 줄로 나눠도 정답** (C1에서 맞힌 방식): `d['m'] = d.groupby('category')['rating'].transform('mean')` → `d['rating'] = d['rating'].fillna(d['m'])`

```python
s = df.sort_values('기준', ascending=False)
s.head(N)['○○'].mean()        # 상위 N개 평균

```

| 코드 | 결과 (정답 40 / 60) |
|---|---|
| ✅ `sort_values(…, ascending=False).head(2)` | **40** |
| 🔇 정렬 없이 `head(2)` | 15 |
| 🔇 `ascending=False` 빠뜨림 | 6 (작은 순) |
| ✅ 정렬 후 `iloc[0]` | **60** |
| 🔇 정렬 후 `loc[0]` | 10 (이름표 0 = 정렬 전 첫 행) |
| 🔇 **정렬 기준 컬럼을 그대로 평균** (`…head(10)['amount'].mean()`) | 평균 낼 컬럼은 문제의 ○○ (`['qty']`) — **A5 · C3 두 번** ⚠️ |

> "amount 상위 N건의 **qty** 평균": 기준 = `sort_values('amount')`, 꺼낼 값 = `['qty']`. 문장에서 **두 컬럼을 따로 짚기**

## 3. True/False 세기 (실수 5 · 사전 52 IQR)

```python
조건.sum()                 # 개수   (= len(df[조건]))
조건.mean()                # 비율
((x < q1 - 1.5*iqr) | (x > q3 + 1.5*iqr)).sum()     # IQR 이상치 개수 — 조건마다 괄호
```

| 코드 | 결과 (정답 4) |
|---|---|
| ✅ `조건.sum()` / `len(df[조건])` | **4** |
| 🔇 `조건.count()` / `len(조건)` | 6 (전체 행 수) |
| 💥 IQR 조건에 괄호 없음 | `TypeError` |

**⚠️ 11/27 A8에서 헷갈린 2가지**

**① 비율은 `df[ ]`로 감싸지 않는다**: 감싸면 걸러내기, 안 감싸면 True/False

| 코드 (Y 2건 / 전체 5건) | 결과 |
|---|---|
| ✅ `(d['coupon'] == 'Y').mean()` | **0.4** (True 2 ÷ 전체 5) |
| 💥 `d[d['coupon'] == 'Y'].mean()` | `TypeError`: Y 행만 남은 **표**의 평균 (글자 열은 평균 불가) |
| 🔇 `d[d['coupon'] == 'Y']['price'].mean()` | 2500.0: 쿠폰 쓴 주문의 price 평균 (비율 아님) |

> 걸러내면 분모(전체)가 사라진다. **개수**는 `len(df[조건])`도 되지만 **비율은 `조건.mean()`뿐**

**② 조건 뒤에 `.mean()` · `.sum()`을 붙이려면 조건을 `( )`로 감싼다**

| 코드 | 결과 |
|---|---|
| 💥 `d['coupon'] == 'Y'.mean()` | `AttributeError: 'str' object has no attribute 'mean'` |
| ✅ `(d['coupon'] == 'Y').mean()` | 0.4 |
| ✅ `cond = d['coupon'] == 'Y'` → `cond.mean()` | 0.4 (변수에 담으면 괄호 걱정 없음) |

> 왜? 파이썬은 **`.`(점)을 `==`보다 먼저** 실행 → `'Y'.mean()`(글자의 평균)이 먼저 돌아서 💥. IQR에 괄호를 치는 것과 같은 이유

**③ ⭐️⭐️⭐️⭐️ "그룹별 비율"은 `groupby(그룹)['is_x'].mean()`** (11/27 C2)

```python
df['is_vip'] = df['member_grade'] == 'VIP'          # True/False 컬럼
r = df.groupby('city')['is_vip'].mean()             # 도시 안에서의 VIP 비율
r.idxmin(), r.min()
```

| 코드 | 결과 (실행 확인) |
|---|---|
| ✅ `groupby('city')['is_vip'].mean()` | 도시 **안** 비율, VIP 0건 도시도 **0.0으로 남음** |
| 🔇 `df[['city', 'member_grade']].value_counts(normalize=True)` | **전체 320건 중** 비율 (부산 13 ÷ 320 = 0.041, 부산 안이면 ÷ 55) + VIP 0건 도시(대전)는 **표에서 사라짐** |

> `value_counts(normalize=True)`는 **컬럼 하나**일 때 "값마다 전체 중 비율": `df['coupon'].value_counts(normalize=True)['Y']` = Y 비율. **그룹 안 비율에는 쓰지 않는다**

> IQR 순서: `q1, q3 = x.quantile(0.25), x.quantile(0.75)` → `iqr = q3 - q1` → 위 한 줄
> **하한이 음수여도 정상** (B7: 하한 −10750). 하한은 데이터 값이 아니라 **경계선**일 뿐이다. 금액처럼 음수가 없는 데이터에서는 이상치가 **위쪽에서만** 나온다 (아래 0건 / 위 2건)

## 4. 조건 행 값 바꾸기 (사전 46) ⚠️ 내 약점 (11/27 A7)

> **걸러서 볼 땐 `df[조건]`, 그 자리에서 바꿀 땐 `df.loc[조건, '열'] = …`**
> "바꿔라 / 낮춰라 / 올려라"는 **행이 하나도 사라지면 안 된다**

**4단계** (예: `size` L의 `price` 500원 낮추고 전체 평균)

```python
cond = d['size'] == 'L'                               # 1. 조건 → True/False
d.loc[cond, 'price']                                  # 2. 바꿀 칸 가리키기 [행 조건, 열 이름]
d.loc[cond, 'price'] = d.loc[cond, 'price'] - 500     # 3. 계산해서 그 칸에 다시 넣기 (= -= 500)
round(d['price'].mean(), 2)                           # 4. 전체 평균
```

```
  size  price
0    L   2500   ← 바뀜
1    M   2000   ← 그대로 (행이 사라지지 않음!)
2    L   3500   ← 바뀜
3    S   1000   ← 그대로        평균 2250.0
```

**내가 실제로 한 실수 + 비슷한 함정** (실행 확인)

| ❌ 코드 | 결과 |
|---|---|
| 🔇 `d[cond]['price'] - 500` (걸러서 계산) | L 행만 남음 → 평균 **3000** (정답 2250) |
| 🔇 `d = d[cond]['price']…` (덮어쓰기) | d가 L 가격 한 줄짜리가 됨 → 다음 문제도 망가짐 |
| 💥 `.transform('value' - 500)` | `TypeError` (글자 − 숫자). transform은 **그룹 평균**용이지 값 바꾸기용이 아님 |
| 🔇 `d[cond]['price'] = …` (사슬) | **원본 그대로** (경고만 뜨고 에러 아님) |
| ⚠️ `d['price'][cond] = …` (사슬, 순서 반대) | 지금은 되지만 pandas 3.0부터 안 됨 → **쓰지 않기** |

**loc이 기억 안 나면, 비상용 np.where** (엑셀 `IF(조건, 맞으면, 아니면)`)

```python
d['price'] = np.where(cond, d['price'] - 500, d['price'])     # 결과 같음 ✅
```

> 문제에서 "복사본에" 하라고 하면 `d = df.copy()` 먼저.
> `.copy()` 기준: `sort_values()`는 처음부터 **새 표** → 필요 없음 / `d = df`는 **같은 표** → 필요 / 걸러낸 결과(`df[조건]`, `drop_duplicates()`)를 바꿀 거면 → 필요

## ➕ 표시는 안 했지만 꼭 넣을 5개 (오답노트에서 가장 많이 틀린 것)

| # | 상황 | 한 줄 | 내 기록 |
|---|---|---|---|
| A | "정수로" / "소수 N째" | `int(x)` / `round(x, N)` — **답 적기 전에 형식부터** | 3번 이상 ⚠️ |
| B | 조건에 맞는 이름이 **여러 개** | `s[s > 기준].index.tolist()` | ⭐⭐⭐ "너무 중요" |
| C | "가장 많은 ○○와 그 개수" | `vc.index[0]` = 이름(누가?) / `vc.iloc[0]` = 값(얼마?) | 11/27 질문 |
| D | "그룹별 N번째로 큰" | groupby 결과는 **이름순** → `sort_values(ascending=False)` 먼저 | |
| E | reset_index를 쓸 때 | 아래 3가지 | 첫 시험 오답 (괄호 · drop=True) |
| F | agg가 기억 안 나면? | **몰라도 된다.** 통계 하나씩 `.mean()` · `.std()` · `.count()`로. 여러 개를 한 번에 보고 싶을 때만 `groupby('g')['x'].agg(['mean', 'std'])` → `t['std'].idxmax()` | 11/27 C5 질문 ⭐️⭐️⭐️⭐️⭐️ |

### E. reset_index — 안 써도 되지만, 쓸 거면 이 3가지

> 안 쓰는 길이 제일 안전하다: 정렬 후엔 **`iloc[N-1]`**, groupby 결과엔 **`index[0]` / `iloc[0]` / `idxmax()`**

```python
df.sort_values('x', ascending=False).reset_index(drop=True).loc[0]['id']   # ① 정렬·필터 뒤 → drop=True
df.groupby('city')['amount'].sum().reset_index()                          # ② groupby 결과 → drop 없이
```

| # | 규칙 | 어기면 (실행 확인) |
|---|---|---|
| ① | 정렬·필터 뒤에는 **`reset_index(drop=True)`** → 그 뒤엔 `loc[0]` = `iloc[0]` | 🔇 reset 없이 `loc[0]` → 정렬 **전** 0번 행 / ⚠️ `drop=True` 빼면 옛 이름표가 **`index` 컬럼**으로 남음 |
| ② | groupby 결과에는 **`reset_index()`** (drop 없이) → 그룹 이름이 **컬럼**으로 살아남은 표 | 🔇 `drop=True`를 붙이면 그룹 이름(답)이 **사라짐** |
| ③ | **괄호 필수** `reset_index()` | 💥 `reset_index.iloc[0]` → `AttributeError` |

## 🧘 제출 전 10초 체크

1. 문제에 "정수" / "소수 N째"가 있나? → `int` / `round(x, N)`: **N을 문제 문장과 한 번 더 대조** (A8: "셋째"인데 앞 문제의 `2`를 그대로 씀 ⭐️⭐️⭐️⭐️)
2. "상위·N번째"가 있나? → `ascending=False` 붙였나, `iloc` 썼나
3. "자기 그룹"이 있나? → `transform`
4. 결과가 **0, NaN, 음수, 전체 행 수**이면 → 🔇 실수를 의심
5. "바꿔라 / 낮춰라 / 채워라"인데 **행 수가 줄었나?** → `df[조건]`으로 걸러 버린 것 → `df.loc[조건, '열'] = …`
