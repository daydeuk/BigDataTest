## 1. 판단 — 가설과 p-value ⭐ (무조건)

### 1-1 가설

| 이름 | 뜻 | 예 |
|---|---|---|
| **귀무가설 (H0)** | "**차이(관계)가 없다**" — 기본 주장 | 수업 전후 점수 평균은 **같다** |
| **대립가설 (H1)** | "**차이(관계)가 있다**" — 보이고 싶은 것 | 수업 전후 점수 평균은 **다르다** |

### 1-2 p-value로 결정

```
p-value < 0.05   →  귀무가설 기각   (차이/관계가 있다, 유의하다)
p-value >= 0.05  →  귀무가설 채택   (차이/관계가 없다, 유의하지 않다)
```

**같은 결론의 여러 표현 (사용자 질문에서 나온 정리)**

| p-value | 귀무가설 | 대립가설 | 유의성 | 쉬운 말 |
|---|---|---|---|---|
| **< 0.05** | 기각 | 채택 | **유의하다** | 차이(관계)가 있다 |
| **≥ 0.05** | 채택 | 기각 | **유의하지 않다** | 차이(관계)가 없다 |

> **어느 가설 기준으로 묻는지** 문제 문장 확인 — 같은 p인데 "귀무가설 기각 여부"면 기각, "대립가설 채택 여부"면 채택
> 가설을 지정 안 하면 **귀무가설 기준**. 엄밀히는 p ≥ 0.05일 때 "기각하지 못한다"
> **p-value** = "귀무가설이 맞다고 칠 때, 지금 같은(또는 더 극단적인) 결과가 우연히 나올 확률". 작으면 "우연이라 보기 어렵다" → 기각. 귀무가설이 맞을 확률이 **아니다**
> **유의수준** = 비교 기준 0.05 (5%). "유의수준 0.01에서"면 0.01과 비교
> 3유형은 **코드를 채점하지 않는다** — 값을 보고 답 칸에 **문제가 정한 형식**(기각/채택, Y/N, 1/0)으로 입력. if문은 판단 보조용 (쓴다면 `0.05`의 0 개수 확인)

> 문제가 유의수준을 다르게 주면(0.01 등) 그 값과 비교
> 답 칸에 "기각" / "채택"을 쓰라고 하면 **문제에 적힌 단어 그대로** (예: "기각", "채택" 또는 "reject")

## 2. t검정 — 평균 비교 (모두 `stats.` 한 줄)

| 조각 | 언제 | 코드 |
|---|---|---|
| **2-1 일표본** | 한 그룹 평균 vs **기준값** ("평균이 70과 다른가") | `stats.ttest_1samp(df['after'], 70)` |
| **2-2 대응** | **같은 사람**의 전후 ("수업 전후 차이") | `stats.ttest_rel(df['after'], df['before'])` |
| **2-3 독립** | **다른 두 그룹** ("A반 vs B반") | `stats.ttest_ind(a, b)` |

**예시 (연습문제와 다른 컬럼) — 실행 결과**

```python
# 2-1 일표본: 수업 전 점수(before) 평균이 60과 다른가?
stat, p = stats.ttest_1samp(df['before'], 60)
print(round(stat, 3), round(p, 3))          # 2.58  0.012  → p < 0.05 → 기각 (평균 62.53, 60과 다르다)

# 2-3 독립: 남학생(M) vs 여학생(F)의 after 평균이 다른가?
m = df[df['gender'] == 'M']['after']        # Day 1 필터 그대로
f = df[df['gender'] == 'F']['after']
stat, p = stats.ttest_ind(m, f)
print(round(stat, 3), round(p, 3))          # -2.476  0.015  → 기각 (M 70.06 vs F 75.37)
```

> 통계량이 **음수**인 건 앞에 넣은 m의 평균이 더 작아서 — 부호는 "어느 쪽이 큰가"일 뿐, 기각 판단은 **p-value**로

> 결과는 **(통계량, p-value)** 두 개 → `stat, p = ...` 로 받는다
> **대응 검정은 순서에 따라 통계량 부호가 바뀐다**: `ttest_rel(after, before)`와 `ttest_rel(before, after)`는 **크기는 같고 부호만 반대** (p-value는 같음) → 문제가 말한 순서대로 (보통 "A − B"면 A가 앞)
> **독립 검정** 그룹 만들기 = Day 1 필터: `a = df[df['group'] == 'A']['after']`
> 등분산 가정 안 함(Welch)이라고 하면 `stats.ttest_ind(a, b, equal_var=False)` (기본은 `True`)

## 3. 카이제곱 — 범주 × 범주 관계

"성별과 합격 여부가 **관련 있는가**" → 둘 다 범주(글자·0/1)일 때

**예시 (연습문제와 다른 컬럼: gender × passed) — 실행 결과**

```python
ct = pd.crosstab(df['gender'], df['passed'])           # 3-1 교차표 (개수 표)
chi2, p, dof, expected = stats.chi2_contingency(ct)   # 3-2 검정
print(round(chi2, 3), round(p, 3), dof)                # 0.621  0.431  1  → p >= 0.05 → 채택 (관련 없다)
```

```
교차표 (gender × passed)     → chi2_contingency
passed   0   1                  돌려주는 것 4개: 통계량, p-value, 자유도, 기대빈도
gender
F       11  22
M       21  26
```

> 자유도 = (행 수 − 1) × (열 수 − 1) = (2−1) × (2−1) = 1

> **반환 순서 4개 외우기**: `chi2, p, dof, expected` (지난번 치트시트 그대로)
> 원본 표(df)가 아니라 **교차표(ct)** 를 넣는다

## 4. 선형회귀 — `smf.ols` ⭐ (요즘 3유형 단골)

### 4-1 적합 — 공식은 글자로 `'y ~ x1 + x2'`

```python
model = smf.ols('after ~ before + hours + attendance + sleep', data=df).fit()
print(model.summary())       # 표로 전부 보기 (확인용)
```

> `~` 왼쪽 = 예측할 것(y), 오른쪽 = 쓰는 변수(x)들을 `+`로
> 2유형 `fit(X, y)`와 모양이 다르다: **공식 글자 + `data=df` + `.fit()`**

### 4-2 계수 · p-value — summary 표에서 바로 읽힌다

```
                 coef    std err          t      P>|t|
Intercept      6.9272      5.688      1.218      0.227
before         0.9678      0.050     19.438      0.000
hours          0.5162      0.086      6.035      0.000
attendance     0.0433      0.042      1.023      0.309
sleep         -0.5878      0.456     -1.288      0.202
```

| 묻는 것 | 코드 | 값 |
|---|---|---|
| hours의 **계수** | `model.params['hours']` | 0.5162 |
| hours의 **p-value** | `model.pvalues['hours']` | 0.0000… |
| **유의하지 않은 변수 개수** (0.05 기준, 절편 제외) | `(model.pvalues.drop('Intercept') >= 0.05).sum()` | 2 (attendance, sleep) |

> 계수 뜻: hours가 **1 늘면** after가 **0.5162 늘어난다** (다른 변수는 그대로일 때)
> ⭐ "유의하지 않은 변수 개수" = 오늘 아침 배운 **True/False `.sum()`** 그대로

### 4-3 R² (결정계수)

```python
print(round(model.rsquared, 3))     # 0.853
```

### 4-4 예측 — 새 값을 **DataFrame**으로

```python
new = pd.DataFrame({'before': [60], 'hours': [10], 'attendance': [90], 'sleep': [7]})
print(round(model.predict(new)[0], 2))     # 69.94
```

> 공식에 쓴 **변수를 전부** 넣어야 한다 (하나라도 빠지면 에러)
> 결과는 Series → `[0]`으로 값 하나

---

### 🔑 외울 카드 — 회귀 모델에서 값 꺼내기 (사용자: "pvalues·rsquared·predict를 몰라서 처음엔 못 했다")

| 묻는 것 | 코드 | summary 표 위치 |
|---|---|---|
| **계수** | `model.params['hours']` | coef 열 |
| **p-value** | `model.pvalues['hours']` (복수형 **s**) | P>\|t\| 열 |
| **R²** | `model.rsquared` | 오른쪽 위 R-squared |
| **예측** | `model.predict(pd.DataFrame({'before': [70], 'hours': [5], 'sleep': [6]}))[0]` | — |
| 유의하지 않은 변수 개수 | `(model.pvalues.drop('Intercept') >= 0.05).sum()` | — |
| **유의한 변수 이름 (여러 개)** | `pv = model.pvalues.drop('Intercept')` → `pv[pv < 0.05].index.tolist()` → `['before', 'hours']` | `index[0]`은 첫 하나만 ❌ |
| p-value가 가장 작은 변수 | `pv.idxmin()` | — |

> 괄호 없음 = 이미 계산된 값 읽기 (`params`, `pvalues`, `rsquared`) / 괄호 있음 = 해 주는 함수 (`predict()`, `summary()`)
> 기억 안 나면 `print(dir(model))` → p·r로 시작하는 이름 찾기. 최후의 수단은 `summary()` 표를 보고 직접 읽기 (소수 넷째까지만 보임)
> ⚠️ `model.params[:, 4]` ❌ — params는 계수만 든 **Series**라 `[:, 열]` 불가. p-value는 따로 `pvalues`
> ⚠️ `df = model.pvalues` ❌ — 원래 데이터 `df`를 덮어씀 → 다음 문제 에러. **새 이름** `pv = ...`

## 5. 로지스틱 회귀 — `smf.logit` + 오즈비

**y가 0/1** ("합격 여부")일 때. 모양은 ols와 똑같고 이름만 `logit`.

```python
model2 = smf.logit('passed ~ hours + attendance', data=df).fit()
print(model2.params['hours'])              # 계수 0.2158
print(np.exp(model2.params['hours']))      # ⭐ 오즈비 1.2409
print(model2.pvalues['hours'])
```

| 묻는 것 | 코드 |
|---|---|
| 계수 | `model2.params['x']` |
| **오즈비** | **`np.exp(model2.params['x'])`** — 계수에 exp |
| p-value | `model2.pvalues['x']` |
| 예측 확률 | `model2.predict(new)` (0~1) |

> 오즈비 뜻: hours가 1 늘면 합격 **오즈가 1.24배** (24% 증가)
> y는 **숫자 0/1**이어야 한다. 'Y'/'N' 글자면 먼저 `df['y'] = (df['y'] == 'Y').astype(int)`
> `.fit()`이 출력하는 "Optimization terminated…" 줄은 정상 (끄려면 `.fit(disp=0)`)

### 3유형 공부 중 나온 질문 (실행으로 확인)

| 질문 | 답 |
|---|---|
| scipy가 뭐? | 통계 검정 도구 상자. `from scipy import stats` = stats 서랍만 꺼내기 |
| 1samp = 일표본? | 그렇다. **1samp** = 1 sample / **rel** = related(대응) / **ind** = independent(독립) |
| 대립가설 채택이라고도 하나? | 한다. 귀무 기각 = 대립 채택 = 유의하다. 문제가 **어느 가설 기준**인지 확인 |
| p-value = 발생 확률? | "귀무가설이 맞다면 이런 데이터가 나올 확률". 가설이 맞을 확률이 아님 |
| 시험도 if문으로? | 코드는 채점 안 함 → 값을 보고 답 칸에 **문제가 정한 형식**(기각/채택, Y/N, 1/0). if는 보조 (`0.05`의 0 개수!) |
| "유의하다"? | p < 0.05 = 기각 = 유의하다. 회귀에선 "유의한/유의하지 않은 변수" |
| p가 0으로 나옴 | 2.6e-31처럼 너무 작아 반올림 → 0.0. 기각 |
| stat이 뭐? | 검정통계량 = 차이 ÷ 흔들림 폭. 클수록 p가 작음 (대략 t > 2면 p < 0.05). 부호는 방향만 |
| 등분산? | 두 그룹 분산이 같다는 가정. 기본 `True`, "가정하지 않음"이면 `equal_var=False` |
| 카이제곱? | 실제 인원 vs "관련 없다면 나왔을 인원(기대빈도)"의 차이. 2×2는 기본 연속성 보정 (1.905 → 1.323) |
| Q1~Q4가 분류? | 아니다. 3유형 **검정**("있나 없나"). 분류는 2유형 예측 모델 |
| OLS? | 최소제곱 선형회귀. 3유형은 **해석**(계수·p-value), 2유형 RF는 **예측** |
| 오즈가 OLS? | 아니다. 오즈 = 될 확률 ÷ 안 될 확률. 오즈비 = `np.exp(logit 계수)` |
| 계수? | "그 변수가 1 늘면 y가 얼마나" (+ 늘어남 / − 줄어듦). 진짜인지는 p-value로 |
