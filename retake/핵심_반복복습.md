## ① True/False: `.sum()` = 개수, `.mean()` = 비율 ⭐⭐⭐ (Day 3 복습 R5)

**조건을 걸면 True/False 목록이 나온다. True=1, False=0이라서:**

| 원하는 것 | 코드 | 계산 |
|---|---|---|
| 몇 건? | `조건.sum()` | True 개수 |
| 몇 %? | `조건.mean()` | True 개수 ÷ 전체 개수 |
| 그룹별 몇 건? | `df.groupby('g')['is_x'].sum()` | |
| 그룹별 몇 %? | `df.groupby('g')['is_x'].mean()` | |

```python
df['is_weekend'] = df['order_dt'].dt.dayofweek >= 5     # ① 조건 → True/False 컬럼
df['is_weekend'].sum()                                   # ② 주말 주문 수
df['is_weekend'].mean()                                  # ③ 주말 주문 비율
df.groupby('city')['is_weekend'].mean()                  # ④ 도시별 주말 비율
```

**왜 평균이 비율인가** — 인천 6건 `[True, True, False, True, True, False]`
→ (1+1+0+1+1+0) ÷ 6 = 4 ÷ 6 = **0.667**. 평균 안에 분자(True 수)와 분모(전체 수)가 다 들어 있다.

**지금까지 따로 배운 게 다 같은 원리였다**

| 언제 | 코드 | 뜻 |
|---|---|---|
| Day 1 복습 isin | `df['city'].isin([...]).sum()` | 개수 |
| Day 2 비율 방법 C | `(df['category'] == '식품').mean()` | 비율 |
| Day 3 Q3 | `...str.endswith('@gmail.com').sum()` | 개수 |
| Day 3 복습 R5 | `groupby('city')['is_weekend'].mean()` | 그룹별 비율 |

**⚠️ 함정 2가지 (실행으로 확인)**

1. **세는 함수를 잘못 고르면 전체 행 수가 나온다**

   | 코드 | 결과 |
   |---|---|
   | `조건.sum()` / `len(df[조건])` | True 개수 ✅ |
   | `조건.count()` / `len(조건)` | **전체 칸 수** ❌ (Day 3 Q3: 40, isin I1: 33) |

2. **필터 후 groupby로 분자 ÷ 분모를 하면 0건 그룹이 NaN** — 지역별 식품 비율 (Day 2 데이터)

   | 지역 | 분자 ÷ 분모 | `is_food` 평균 |
   |---|---|---|
   | 대구 (식품 0건) | **NaN** | **0.0** |
   | 가장 낮은 지역 `idxmin()` | 경기 ❌ | **대구** ✅ |

   > 필터하면 0건 그룹은 결과에서 **사라진다.** "가장 낮은" 문제에서 틀린다 → **True/False 컬럼 + mean**이 안전

> **시험에서 "비율"이 나오면**: 조건으로 True/False → `mean()`. 그룹별이면 `groupby` 사이에.
> 분모가 "○○ 중에서"로 바뀌면 먼저 거른다: `s = df[df['region'] == '서울']` → `(s['category'] == '가전').mean()`

## ② 조건에 맞는 "이름"을 전부 꺼내기: `.index.tolist()` ⭐⭐⭐ (Day 6 Q8)

**결과가 Series일 때, 조건으로 거른 뒤 이름표(index)를 목록으로 꺼낸다.**

```python
pv = model.pvalues.drop('Intercept')
pv[pv < 0.05]                   # 조건에 맞는 것만 (Series: 이름 + 값)
pv[pv < 0.05].index             # 이름표만
pv[pv < 0.05].index.tolist()    # ⭐ 이름 목록 → ['before', 'hours']
```

| 코드 | 결과 | 언제 |
|---|---|---|
| `.index[0]` | `'before'` (첫 번째 **하나**) | "**가장** 많은 / 1등" — value_counts·정렬 결과 |
| **`.index.tolist()`** | `['before', 'hours']` (**전부**) | "~**인 것들**", 몇 개인지 모를 때 |
| `(조건).sum()` | `2` | 개수만 물을 때 (① True/False) |
| `.idxmax()` / `.idxmin()` | 가장 큰 / 작은 이름 하나 | "가장 ~한" |

**어디서나 같은 모양** — 결과가 "이름표 + 값"인 Series면 다 된다

| 상황 | 코드 |
|---|---|
| 유의한 변수들 (3유형) | `pv[pv < 0.05].index.tolist()` |
| 건수가 7건 이상인 지역들 (1유형) | `vc = df['region'].value_counts()` → `vc[vc >= 7].index.tolist()` |
| 평균이 2만 이상인 분류들 (1유형) | `g = df.groupby('category')['price'].mean()` → `g[g >= 20000].index.tolist()` |
| 결측 있는 컬럼들 | `s = df.isnull().sum()` → `s[s > 0].index.tolist()` |

> ⚠️ 이번 Q8은 유의한 변수가 1개라 `index[0]`도 맞았다 → **여러 개일 수 있으면 무조건 `tolist()`**
> `tolist`는 **괄호 필수** — `tolist` (괄호 없음) 하면 함수 이름이 출력됨 (지난번 Day 11 오답)
