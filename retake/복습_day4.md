## 1. 내가 틀린 것 (모두 고쳐서 통과)

| 조각 | 실수 | 기억할 한 줄 |
|---|---|---|
| 2-2 결측 | `X_test['age'] = X['age'].fillna(m)` → test 290명 나이가 train 나이로 (에러 없음!) | 채우는 줄은 **`X ← X`, `X_test ← X_test`** |
| 2-2 결측 | "중앙값"인데 `mean()` | 문제가 정한 방법 그대로 → `median()` |
| 4-1 분할 | `stratify=y` 빠뜨림 → Q3 답 0.8471 (정답 0.8261) | 분류 = `test_size=0.2, random_state=42, stratify=y` 세트 |
| 4-2 학습 | `model.predict(X_train, y_train)` → TypeError | 공부 = **`fit`**, 맞히기 = `predict` |
| 4-4 점수 | `round(…, 4)` 빠뜨림 ⚠️ 반복 | 값을 출력하면 **형식부터** 확인 |
| (메모) | `X_test = train.drop(...)` | **`test.drop`** |

## 2. 5단계 한 장 (번호 = 단계-조각)

```
1 탐색       1-1 불러오기 · 1-2 훑어보기 (shape, isnull, 정답 비율 — test 행 수 기억!)
2 전처리①    2-1 나누기 (y / X / X_test) · 2-2 결측 (train 기준, 둘 다)
3 전처리②    3-1 인코딩 (concat([X, X_test]) → get_dummies → iloc으로 다시 나누기)
4 모델링     4-1 분할 · 4-2 학습(fit) · 4-3 예측 · 4-4 점수 (정답 먼저)
5 제출       5-1 다시 학습 fit(X, y) · 5-2 저장 (X_test, index=False) · 5-3 확인 (행 수 = test)
```

| 평가지표 | 예측 | 제출 |
|---|---|---|
| **ROC-AUC** | `predict_proba(X)[:, 1]` (확률) | 확률 |
| **F1 · accuracy** | `predict(X)` (0/1) | 0/1 |

## 3. ⭐ 기억할 개념

| 개념 | 한 줄 |
|---|---|
| stratify | **정답 비율 그대로 나눠 줘** (층화). 분류만 — 회귀는 그룹이 없어 에러 |
| `random_state` | 무작위 고정. 숫자는 아무거나, 고정이 핵심 |
| `n_estimators` | 나무 수. 100 (기본값) |
| 4-1~4-4 | **모의시험**. 채점엔 안 들어가지만 "망가졌나" 확인용 계기판 |
| `fit` 다시 | 숨겨 둔 200명까지 1000명 전부로 처음부터 다시 공부 |
| 모델 바꾸기 | 거의 필요 없음 (모델 차이 0.04 vs 0/1 제출 실수 0.10) |
